# Palvelio architecture

Palvelio is a TanStack Start/React 19 website hosted on Netlify. It connects customers and service providers through enquiries, rather than live bookings or payments.

- `src/components/MarketingPage.tsx`: homepage, English/Finnish/Arabic copy, language selector, service finder, provider section, native dialog and enquiry submission.
- `src/styles.css`: Nordic forest-green/ivory/lime design, responsive layouts, RTL styles, reduced-motion support.
- `src/data/site.ts`: site title and social description.
- `src/routes/`: file routes and document metadata. Route tree is generated by the framework.
- `public/__forms.html`: deploy-time registration for the enquiry form; every submitted field must match this definition.

Keep translations aligned. Set both document language and direction when switching language. Browser storage belongs in effects. Use semantic HTML, keyboard focus states, labelled form fields and native validation. Preserve native dialog close and keyboard behavior.

Enquiries POST URL-encoded data to `/__forms.html`, not `/`, because the SSR catch-all intercepts the latter. Check HTTP errors and reject unchanged static registration HTML before displaying success. Preserve input on error. The form distinguishes customer/provider with `role`; services 0–3 mean cleaning, moving, assembly and repairs. Do not invent ratings, verified providers or guaranteed response times.

Netlify Forms stores enquiries. No custom backend, user accounts or application database is implemented. Language preference alone is persisted locally. Requests do not confirm a booking. For future persistent application records use Netlify Database; keep secrets server-side. Do not add an Open Graph image because the platform supplies one.

Use pnpm and Node 22.13+ or 24. Build/validation is handled by the platform in automated editing runs; do not run builds, development servers or tests during those runs.
